Customize Your Placeholder

By default, each size always gets the same photo. Options let you choose a category, get a random photo instead, switch to black and white, or use Scotty, standing or as a round profile picture, or choose a solid color placeholder.

OptionWhat It DoesExample
?category= Only photos from one category: campus, classrooms, labs or life.
?random A different photo every time. A page shows one image per address, so number them for several on one page: ?random=1, ?random=2.
?gray Grayscale. ?grayscale works too, and so does /g/ in front: /g/400/300.
?scotty Scotty instead of a photo, standing on the bottom edge.
?scotty&white Scotty on plain white, for a logo in a site's header.
?profile Scotty as a round profile picture, for people who don't have a photo yet. Always square: /96?profile.
?solid A solid color placeholder instead of a photo. The default is Steel Gray.
?solid&text A solid color placeholder with its width × height near the top.

Add options after a ?, joined with &, in any order: /400/300?category=labs&gray. Category and random options apply only to photos. Leave them out when using Scotty, a profile picture or a solid color placeholder. Use ?white only with ?scotty and ?text only with ?solid. If an option is misspelled or isn't supported, an error message will list the available options.

File Types

Photos are JPEGs; add .webp after the size for a smaller WebP file: /400/300.webp?category=campus. Scotty, profile pictures and solid colors are SVG, so they stay sharp at any size. For a PNG instead, such as for email or a document that doesn't take SVG, add .png after the size: /400/300.png?solid&text. A .jpg on a photo or .svg on the others also works.
