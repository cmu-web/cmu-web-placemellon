Customize Your Placeholder

Choose a campus photo, Scotty or a simple placeholder, then pick the size and file type for your layout. Each example opens the Builder with those choices selected.

Choose a Photo

Campus photography from CMU Selects, cropped to fit your layout. A size and category always give the same photo, so a mockup stays familiar as you work. The Builder has two additional photo options: Random Photo Each Time gives a new photo on each request, and Grayscale removes the color.

Choose a Size

Set the width and height in pixels, from one to 2048. Leave the height empty for a square. Profile pictures are always square; bio placeholders start at 600 by 750 unless you have entered a size.

Photos are cropped to fill the image. Wide images favor landscape photos and tall images favor portraits. Preview the crop at the proportions your layout uses.

Choose a File Type

ImageFormatUse It For
PhotosJPEG or WebPWeb pages and mockups. JPEG is the default; WebP usually produces a smaller file.
Scotty, Profile Pictures, Bio Placeholders and Solid ColorsSVGWeb pages and layouts that need to scale. Vector artwork stays sharp at any size.
Scotty, Profile Pictures, Bio Placeholders and Solid ColorsPNGEmail, slides and documents that don't take SVG. Export enough pixels for the size you'll use.

Check Before You Share

  • Check the crop in your layout. Preview wide, tall and mobile versions before settling on a size.
  • Keep the image proportions. Match the requested width and height to the space it fills.
  • Use placeholder photos only in mockups. To use one of the photos on a live site, find the original and download it from CMU Selects. Graphics, like Scotty, the bio placeholder and solid colors, are fine on live sites.
