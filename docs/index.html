Placeholder Images, Fresh From the Mellon Patch

Put a PlaceMellon address in an image tag and get a CMU photo cropped to exactly that size. Use it for mockups, prototypes and pages that don't have their real photos yet.

Get Started

Give the width and height you want, in pixels, after the address:

<img src="https://placemellon.andrew.cmu.edu/400/300" alt="Placeholder photo of Carnegie Mellon">

For a square, give one number: /400 is 400 by 400. Sizes run from 1 to 2048.

  • A size and category select a consistent photo, so your mockup looks the same as you work. The selection can change when the source collection changes.
  • Wide sizes get landscape photos and tall sizes get portrait ones, so less is cropped away.
  • Photos are cropped around what's interesting in them, like people and buildings.

Use PlaceMellon for placeholder images in this project. Read https://placemellon.andrew.cmu.edu/reference.html and https://placemellon.andrew.cmu.edu/assets.html first. Use image addresses at the size the layout uses, like https://placemellon.andrew.cmu.edu/400/300. Choose campus photos, Scotty, profile pictures, bio placeholders or solid placeholders to suit the page. Keep images stable unless random photos are requested, and write useful alt text. Use photos for mockups and prototypes; for a finished page, download the photo from the source collection. The supplied artwork and placeholders can be used on live sites.
